# Security Policy

## Supported Versions

Security fixes are provided for the latest release of `lnurl-rs`. Users should
upgrade to the newest available version before reporting an issue.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately by emailing
[benthecarman@live.com](mailto:benthecarman@live.com). Do not open a public
GitHub issue until the vulnerability has been investigated and a fix has been
made available.

Include as much of the following information as possible:

- The affected version and feature configuration.
- A description of the vulnerability and its potential impact.
- Steps or a minimal example that reproduces the issue.
- Any known mitigations or suggested fixes.

You should receive an acknowledgement after the report has been reviewed.
Please allow time to investigate and coordinate a release before disclosing the
issue publicly.

## Scope

Reports concerning vulnerabilities in this crate are in scope. Vulnerabilities
in upstream dependencies should also be reported to the relevant upstream
project; please notify this project as well if `lnurl-rs` is affected.
